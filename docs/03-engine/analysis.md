# 03-engine: 挙動の分析

状態: 確定(指標は検証しながら足す)

討論者の挙動を、保存済みのデータから同じ物差しで数字にする。プロンプトや仕組みを変えた前後で、議論を比べるために使う。

## 方針

- 挙動の理由は、討論者に説明を書かせるのではなく、保存済みのデータから分析して把握する(→ `decisions.md`「方針を先に書かせる案は採らない」)。
- 分析は議論に一切影響しない。データを読むだけで、何も書き込まない。

## 分析CLI

| 項目 | 内容 | 状態 |
|---|---|---|
| 置き場所 | `tools/analyze-debate/`(開発用CLI。本番スタックには含めない) | 確定 |
| 使い方 | `npm run analyze-debate -- <議論ID> [<議論ID> …]`。2件以上渡すと、指標を横に並べて比べる | 確定 |
| 読むデータ | DynamoDBのDebatesとMessages。テーブル名はスタック(`AgorawlData`)の出力から取る | 確定 |
| 読まないデータ | Lambdaのログ(CloudWatch Logs)。必要になったら足す | 確定 |
| 指標の計算 | AWSに触れない関数に分け、テストを書く | 確定 |

## 指標

議論ごとに、先攻・後攻それぞれについて出す。

| 指標 | 中身 |
|---|---|
| 議論の概要 | テーマ、立場、ターン数、終了理由、投了した側。審判の判定があれば、審判ごとの基準別の点数・合計・勝者 |
| 主張の件数 | 最初の発言(立論)の主張の数、途中で足した主張の数、最終の主張の数 |
| 相手に触れた主張 | 途中で足した主張のうち、内容に「相手」を含むものの件数とID |
| 主張の点数の変化 | 自分の発言ごとに、前回の自分の作戦メモと同じIDの主張の点数を比べ、上げた・下げた・同じだった回数を数える。最終の点数の分布も出す |
| 主張の状態 | 捨てた(`abandoned`)主張の件数。自分の発言ごとの、守っている(`defending`)主張の数 |
| 発言の形 | 攻防の発言(自分の最初の発言=立論と、投了の発言を除く)について、字数の平均、相手の発言の引用(「相手は『」「相手が「」などの形)の回数の平均、論点を並べる形(「第一に」「まず、」「次に、」「最後に、」「三つ」「3点」など)を含む発言の割合、1回の発言で動かした反論の数の平均(前回の自分の作戦メモと比べて、追加した反論と内容・点数・状態が変わった反論の数) |
| 撤回の宣言 | 主張を新しく捨てた発言(前回の自分の作戦メモでは守っていた主張を、今回捨てた発言)の数と、そのうち発言に撤回の言葉(「撤回」「取り下げ」「取下げ」)を含むものの数。投了の発言は数えない |
| 見込みと審判の点数 | 判定があり、審判が主張ごとの点数を付けている議論のみ。最終の作戦メモの主張の点数(討論者の見込み)と、審判の点数を同じIDで比べる。差(見込み − 審判)の絶対値の平均、見込みが審判より高かった件数・低かった件数・同じだった件数、審判が3点以下と見た主張のうち討論者が守っていた(`defending`)件数 |

- 「相手に触れた主張」は、主張に反論の言い直しが混ざっていないかの目安。主張は「自分の立場が良い理由で、相手の主張がなくても成り立つもの」としている(→ README「作戦メモ」)。「相手」と書かずに言い直している主張は拾えない。
- 「途中で足した主張」は、最終の主張一覧のうち、最初の発言の主張一覧にないIDのもの。
- 点数の変化は、作戦メモに保存された全項目の一覧(エンジンが前回と合わせたもの)で比べる。モデルが出力しなかった項目は、前回の点数のまま引き継がれるので「同じ」に数えられる。
- 投了の発言も、作戦メモを持つので数える。司会の発言(司会を廃止する前に保存した議論にある)は数えない。
- 1回の発言で動かした反論の数は、そのターンで取り上げた反論の数の目安(論点を選んで深く論じているかを見る。Issue #27)。
- 論点を並べる形は、相手の主張をいくつも扱うときだけでなく、1つの主張を何段にも掘り下げるときにも出るため、両者を見分けられない。論点を選んでいるかは、動かした反論の数で見る。
- 発言の形の指標は、言葉の形で判定する目安。相手の発言の引用の回数は、1回の発言で取り上げた相手の論点の数の目安として使う(発言が長くなる主な要因。Issue #27 の分析)。
- 撤回の宣言は、言葉を含むかで判定する目安。言葉を使わずに撤回を述べた発言は拾えず、撤回以外の文脈でその言葉を使った発言も数えてしまう。
- 審判が複数いる場合、見込みと審判の点数の比較には、1人目の審判の点数を使う。
