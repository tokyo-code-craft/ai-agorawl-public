# 06-explainer-video: 解説動画の自動生成

## 目的

- システム完成後、解説動画をYouTubeに公開する。ずんだもん解説のようなコミカルな掛け合い形式。
- 動画は自動生成にする。台本、音声、映像の工程をコードで動かし、手作業を減らす。
- 動画を作る道具は、このリポジトリの持ち主が動画を作るためのもの。リポジトリをcloneした人が自分で作れる状態にするのは、議論のシステム(AI言い合いバトル)までで、動画の作成は含めない。

## 工程

| 工程 | 入力 | 出力 | 方針 | 状態 |
|---|---|---|---|---|
| ① 台本生成 | 解説したい内容(仕様書、開発の経緯 #6 など) | 台本データ(JSON) | Bedrockで下書きを作り、ユーザーが直して確定する。確定した台本データはリポジトリに置き、そこから音声と映像を作る。使い勝手は作りながら見直す | 推奨 |
| ② 音声合成 | 台本データ | セリフごとの音声と長さ | VOICEVOX(Dockerで起動、無料・アカウント不要)。ずんだもんと四国めたんの声 | 確定 |
| ③ 映像合成 | 台本、音声、キャラクター画像、画面の映像 | 動画ファイル(mp4) | Remotion(Reactで映像を書く)で生成(字幕、立ち絵の切り替え、口の開閉、画面の映像の重ね合わせ) | 確定 |
| ④ 公開 | 動画ファイル | YouTubeへの投稿 | 当面は対象外(mp4出力まで)。手動アップロード | 推奨 |

- 台本データ(話者、セリフ、表情)が工程間の共通の取り決め。各工程を個別に差し替えられる。
- コマンド1つ(`npm run make -- scripts/<台本>.json`。台本を複数渡すと、つないで1本にする)で、音声を作ってから mp4 にするところまで通しで動く(→ `video/README.md`)。

## 台本データ

1本の動画を、段階ごとの JSON に分けて書ける(1つでもよい)。確定した台本は `video/scripts/` に置き、コミットする。

- 段階ごとの台本は、それだけで動画にできる(作りながら確かめる用)。題・背景・BGM も段階ごとに書く。
- 仕上げは、段階の台本を順に渡して、1本につないで作り直す(`npm run make -- <台本1> <台本2> …`)。行を順につなぎ、題・背景・BGM は最初の台本のものを使う。画面の映像は、つないだ後の前の行から続く。

```json
{
  "title": "試しの掛け合い",
  "lines": [
    { "speaker": "zundamon", "text": "作りはAWSとBedrockなのだ!", "reading": "作りはエーダブリューエスとベッドロックなのだ!", "expression": "smile" },
    { "speaker": "metan", "text": "へえ、勝ち負けはどうやって決めるの?" }
  ]
}
```

| 項目 | 内容 | 状態 |
|---|---|---|
| `title` | 動画の題。画面の左上に出す | 確定 |
| `background` | 背景の画像。省ける(省くと既定の色)。最初の1本の背景は、ユーザーが Gemini で作った法廷の絵(素材の規約によるクレジットは要らない)。`video/` からの道のり。画面いっぱいに広げ、縦横の比が違えばはみ出た分を切る。ファイルが手元にないときは、既定の色で作る | 確定 |
| `bgm` | BGM。省ける。`file`(曲のファイル。`video/` からの道のり)と `volume`(0〜1。省くと 0.04)。動画ごとに曲を変えられる。曲のファイルが手元にないときは、BGM なしで作る | 確定 |
| `lines[].speaker` | 話し手(`zundamon` / `metan`)。どの声と立ち絵を使うかは、話し手の設定(`video/src/characters.ts`)で決める | 確定 |
| `lines[].text` | 字幕に出す文 | 確定 |
| `lines[].wait` | 話し始める前の間(秒)。省ける。間の間、その行の画面の映像を先に出す。画面の操作(文に色を塗るなど)を見せ終えてから話し始めたいときに書く | 確定 |
| `lines[].reading` | 読み上げる文。省ける。字幕と読み方を変えたいときだけ書く(英語のつづりなど、VOICEVOX が読み間違える語) | 確定 |
| `lines[].expression` | 表情の名前。省くと `normal`。使える表情は、話し手の設定にあるもの | 確定 |
| `lines[].screen` | その行で出す画面の映像。省くと、前の行の画面を続けて出す。`null` で画面を消す(→「画面の映像」の「台本での指定」) | 推奨 |

## `video/` の構成

| 場所 | 中身 | コミット |
|---|---|---|
| `video/README.md` | 使い方、素材の入手の手順 | する |
| `video/package.json` | `video/` だけの依存関係。npm workspaces に入れず、`video/` で別に `npm install` する | する |
| `video/scripts/` | 確定した台本(JSON) | する |
| `video/thumbnails/` | サムネイルの中身の指定(JSON。→「サムネイル」) | する |
| `video/src/` | 立ち絵の PNG を作る CLI、音声を作る処理、Remotion の映像、話し手の設定 | する |
| `video/assets/` | 立ち絵の PSD、背景の画像、BGM の曲、字体などの素材 | しない |
| `video/public/` | 素材から作った立ち絵の PNG、音声(wav)。Remotion が読む | しない |
| `video/out/` | 作った動画(mp4)とサムネイル(PNG)。作るたびに連番を付け(`<台本の名前>-001.mp4`、`-002.mp4` …)、前の動画は消さない。要らない動画はユーザーが手で消す | しない |

- npm workspaces に入れない理由: 入れると、リポジトリのルートで `npm install` するだけで、Remotion と動画を書き出すためのブラウザ(百数十MB)まで入る。動画づくりは、clone した人が作れる範囲に含めない(→「目的」)。

## 音声

| 項目 | 内容 | 状態 |
|---|---|---|
| エンジン | VOICEVOX のエンジンを Docker で手元に起動し(`http://localhost:50021`)、HTTP で呼ぶ | 確定 |
| 声 | ずんだもん(ノーマル、スタイルの ID 3)、四国めたん(ノーマル、ID 2) | 推奨 |
| 作り直し | 同じ話し手・同じ読みの音声は作り直さない(`video/public/voice/` に残す)。台本の一部を直したときは、直した行だけ作る | 推奨 |
| 「・・・」の間 | 読みの中の「・・・」(中黒2つ以上)と「…」は、1.0秒の間にする(VOICEVOX は読点と同じ短い間にするため)。文の頭にあれば、話し始める前に1.0秒あける。文の終わりにあれば何もしない(次のセリフまでの間がある)。字幕は書いたとおりに出す | 確定 |

## 映像

| 項目 | 内容 | 状態 |
|---|---|---|
| 大きさ | 1920×1080、30fps | 推奨 |
| 並べ方 | セリフの音声を順に並べ、間を空ける(最初のセリフの前に1.5秒、最後のセリフの後に3秒、セリフの間に0.3秒) | 推奨 |
| 始めと終わり | 始めは黒から1秒で明るくし、0.5秒おいて最初のセリフ。終わりは最後のセリフの後に2秒そのまま見せ、1秒で黒にする | 確定 |
| 立ち絵の位置 | 画面の左に四国めたん、右にずんだもん。腰から上を出す。2人とも同じ倍率で縮め、頭のてっぺん(絵の透けていない部分のいちばん上)の高さをずんだもんに合わせる | 推奨 |
| 立ち絵の向き | 2人とも画面の真ん中(相手の側)を向かせる。四国めたんの絵は左を向いているため、左右を反転する(配布元の規約で、加工しての利用はできる) | 推奨 |
| 話している側 | 話している側の立ち絵をはっきり出し、もう片方は暗くする。大きさと位置は変えない(切り替わるたびに絵が動いて見えるため) | 推奨 |
| 表情 | 話し手ごとに、その話し手の直前のセリフの `expression` | 推奨 |
| 口パク | VOICEVOX が返す音の長さ(モーラごとの子音と母音の長さ)から、母音の間だけ口を開けた絵にする。撥音「ン」、促音「ッ」、無声化した母音、間では閉じる | 推奨 |
| BGM | 動画の最初から最後まで流し、曲が短ければ繰り返す。最初の1秒で大きくし、最後の2秒で小さくして消す。音量は一定(セリフの間だけ下げることはしない) | 推奨 |
| 題 | 画面の左上に、白い札にのせて出す(背景の画像の上でも読めるように) | 推奨 |
| 字幕 | 画面の下の真ん中に、話し手の名前と `text` を出す。枠の色は話し手の色。次のセリフが始まるまで残す | 推奨 |
| 文字の字体 | 字幕・題などの文字は、日本語の字体(Noto Sans JP、なければ游ゴシック、メイリオ)で出す。中国語の字形(「判」など)にしない | 確定 |

## 立ち絵

| 項目 | 内容 | 状態 |
|---|---|---|
| PSD から PNG へ | 立ち絵の PSD(`video/assets/`)から、表情ごとに口を閉じた絵と開いた絵の2枚の PNG を作り(`npm run psd -- build`)、Remotion で切り替える | 推奨 |
| 表情の設定 | 表情ごとに、表示にするレイヤーの名前を話し手の設定(`video/src/characters.ts`)に書く。レイヤーの名前の決まりは PSDTool に合わせる(「!」で始まるグループは常に表示、「*」で始まるものは同じ親の中から1つだけ表示)。レイヤーの木は `npm run psd -- tree <話し手>` で見る | 推奨 |
| 表情 | ずんだもんと四国めたんの両方に、`normal`(普通)、`smile`(にっこり)、`surprised`(驚き)、`troubled`(困り)を置く | 推奨 |
| PSD がない話し手 | 仮の絵(話し手の色の形に名前を書き、口の開閉を線で表す)で表示する | 推奨 |

## 画面の映像

| 項目 | 内容 | 状態 |
|---|---|---|
| 録り方 | Playwright(ブラウザを自動で動かす道具)で本番の画面を操作し、録画する。画面を直した後も、コマンドで録り直せるようにする | 確定 |
| 費用 | 終わった議論を開いて見せる場面は、費用がかからない。議論の作成から録る場面は、録るたびに Bedrock の費用がかかる | 確定 |
| 録る場面の単位 | 場面(例: 表紙、ログイン、作成の画面、議論の画面)ごとに録り、場面の ID の名前のファイルにする。場面と操作は `video/src/record/scenes.ts` に書く | 推奨 |
| 録り方の使い分け | 場面ごとに、動画で録るか、画面の写真を撮るかを選ぶ。操作の動き(入力、ボタン、窓の開閉、発言が届く様子)を見せる場面は動画、読ませたい場面(判定の内訳など)は写真 | 確定 |
| 写真の動かし方 | 写真は、出している間、少しずつ拡大する。台本で、拡大の倍率と、寄せる場所を指定できる | 推奨 |
| 議論を作る場面 | 場面ごとに使い分ける。作成の画面の入力と AI を選ぶところまでは、作らずに録る(費用がかからない)。作って発言が届く様子を見せる場面は、本当に作って録る(Bedrock の費用がかかる。録る前にユーザーに確かめる) | 確定 |
| 見せる議論 | テーマ「きのこの山とたけのこの里はどっちが美味い?」、先攻「きのこの山」、後攻「たけのこの里」。動画のために本当に作り、作る様子を録る。終わった後の場面(議論の画面、結果、判定)も、この議論で録る | 確定 |
| ログインのアカウント | デモのアカウント `demo@example.com`(画面にメールアドレスが映る。パスワードは伏せ字で映る。視聴者が使うのと同じアカウントで見せる)。メールアドレスとパスワードは環境変数(`AGORAWL_USER`、`AGORAWL_PASSWORD`)で渡し、コミットしない | 確定 |
| 一覧を空にする | 台本で「まだ議論を動かしていない」と見せるため、録る前に、管理者がすべての議論を隠す(→ `04-app`「議論を隠す」)。デモのアカウントには、隠した議論は見えない | 確定 |
| 文の強調 | 台本で発言の一部を取り上げるときは、録るブラウザの中だけで、その文に蛍光ペンのような色を付けて録る(本番の画面にはない飾り。録った映像にだけ映る) | 確定 |
| 録る画面の大きさ | パソコンの画面(1280×720 の表示を、1.5倍の細かさで録る) | 推奨 |
| 置き場所 | 録ったものは `video/public/screens/`(コミットしない)。作った議論の ID は `video/record.json` に書く(コミットする。秘密ではない) | 推奨 |
| 台本での指定 | 行の `screen` に、場面の ID を書く(例: `{ "id": "debate-view" }`)。動画の場面は、同じ ID が続く間、続けて再生する。`start`(秒)で、再生を始める位置を指定できる。写真の場面は `zoom`(倍率)と `focus`(寄せる場所。画面の幅と高さに対する割合 `[x, y]`)を指定できる | 推奨 |
| 動画の中の配置 | 画面の映像を出す間は、画面を大きく真ん中の上に出し、2人の立ち絵は左右の下に小さく出す。字幕は画面の下に重ねる。題は出さない。画面の映像を出さない間は、今の配置(2人を大きく出す) | 確定 |

## サムネイル

YouTube の動画の一覧に出す絵。動画と同じ素材(背景、立ち絵、録った画面、字体)から、コマンドで作る。

| 項目 | 内容 | 状態 |
|---|---|---|
| 大きさ | 1280×720 の PNG(YouTube の推奨。2MB 以下) | 確定 |
| 作り方 | Remotion の静止画(`renderStill`)で作る。`npm run thumbnail -- thumbnails/<名前>.json` で、`video/out/<名前>-<連番>.png` に出す(作るたびに連番を付け、前の絵は消さない) | 確定 |
| 中身の指定 | `video/thumbnails/<名前>.json`(コミットする)に、題、題の下の行、札の文字、背景、真ん中に出す画面、2人の表情を書く。題と題の下の行は、色を変える区切りごとに文字と色(`pro`(先攻の橙)、`con`(後攻の青)、`alert`(赤)、なし(濃い灰色))を並べる | 確定 |
| 配置 | 背景(議論会場。少し暗くする)の上に、上の帯(濃い色の半透明)に題と題の下の行を出す。真ん中に録った画面を白い枠で囲み、少し傾けて置く。左に四国めたん、右にずんだもん。左下に黄色い札(「概要編」など) | 確定 |
| 立ち絵 | 動画と同じく、2人を同じ倍率で縮め、頭のてっぺんの高さをそろえる。四国めたんは左右を反転する | 確定 |
| 真ん中の画面 | 録った画面の映像(`video/public/screens/<ID>.mp4`)の最後のコマを切り出して使う。写真の場面(`.png`)ならそのまま使う | 確定 |
| 字体 | 題・題の下の行・札は Dela Gothic One(表紙と同じ。SIL Open Font License 1.1)。白で縁取る。字体のファイルは `video/assets/fonts/DelaGothicOne-Regular.ttf` に置く(素材なのでコミットしない。入手の手順は `video/README.md`)。ないときは、日本語の太いゴシックで作る | 確定 |
| 概要編の中身 | 題「AI同士で議論させてみた」(「AI同士」は先攻の色、「議論」は後攻の色)。題の下の行「きのこvsたけのこ、AIの判定は…!?」(「きのこ」は先攻の色、「たけのこ」は後攻の色、「AIの判定は…!?」は赤)。札「概要編」。真ん中はカットイン(場面 `create`)。四国めたんは驚き(`surprised`)、ずんだもんはにっこり(`smile`) | 確定 |

## 話し手

| 項目 | 内容 | 状態 |
|---|---|---|
| キャラクター | ずんだもんと四国めたん(東北ずん子・ずんだもんプロジェクト)の2人の掛け合い | 確定 |
| 役回り | ずんだもんが解説役、四国めたんが聞き役。作りながら見直す | 推奨 |
| 声 | VOICEVOX の「ずんだもん」と「四国めたん」 | 確定 |
| クレジット | YouTube の概要欄(動画の下に出る文章の欄)に書く。動画の中には出さない。声は「VOICEVOX:ずんだもん、VOICEVOX:四国めたん」(音源の規約で、見る人が探せば見つかる場所に書くことが条件)。立ち絵は「立ち絵:坂本アヒル」(規約の条件ではないが書く) | 確定 |
| 立ち絵 | 坂本アヒルさんの立ち絵(口パクや表情の差分つきのPSD)。配布元の規約は「公式の規約の範囲なら何に使ってもよい」で、上の「キャラクター」の公式の規約(ガイドライン)に従えば使える。使い方は →「立ち絵」 | 確定 |
| 素材の置き場所 | 立ち絵などの素材は、リポジトリに入れない(再配布してよいかが素材ごとに違うため)。`video/assets/`(コミットしない)に置き、入手の手順を `video/README.md` に書く | 確定 |
